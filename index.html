Architecture

Seven steps from a CSV on GitHub to partitioned JSON in HDFS.

Hive and the Pandas ELT both read the same raw file, in parallel.

01

Source

penguins.csv

The Palmer Penguins file on GitHub.

02

Ingest

wget + hdfs dfs -put

Downloaded to the sandbox, then pushed into HDFS.

03

Store

HDFS /user/maria_dev/datasets

The raw file both branches read.

04

Branch A · analysis

Hive penguins_db.penguins_raw

Counts, averages and missing values in SQL.

05

Branch B · in parallel

WebHDFS InsecureClient → Jupyter + Pandas

Clean, impute and add a kg column.

06

Upload

HDFS /user/maria_dev/datasets/clean/penguins_clean.csv

The cleaned file goes back into HDFS.

07

Process

PySpark: schema, filter, sort, cache

Writes JSON partitioned by species.

Output
/user/maria_dev/spark/output/penguins

Analysis

The notebook's charts, from the cleaned data.

Click any chart to enlarge it.

Three things the data shows.

Gentoo are the heaviest

5.08 kg on average

They also have the longest flippers, at 217.19 mm.

Islands split by species

  • Chinstrap live only on Dream
  • Gentoo live only on Biscoe
  • Adelie live on all three islands

Data quality was high

Only 2 fully empty rows and 11 missing sex values.
